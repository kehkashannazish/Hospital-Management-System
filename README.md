# Hospital Management System

This is a C++ project made as part of my academics. It uses different data structures to manage basic hospital operations.

## Features
- Add and display patient details
- Manage the patient queue
- Handle emergency patients
- Search patients using their ID
- Add doctors and search for specialists

## Data Structures Used
- Arrays
- Queue
- Priority Queue
- Binary Search Tree

## Language Used
- C++

## How to Run
Compile the code using a C++ compiler and run the program.

This project helped me practise data structures and understand how they can be used in a simple real-world application.
